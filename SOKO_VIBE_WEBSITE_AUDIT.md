## 1. Decision: Public Surface Moved to Static HTML

The Flutter Web root (`web_landing/`) cannot deliver per-page SEO or Core Web Vitals (single `index.html` SPA). The public marketing surface was therefore moved to a static HTML/CSS/JS system inside `soko_langu/server/landing/`, served by the existing Express server. The Flutter mobile app (`soko_langu/`) is untouched. Firebase/APIs/infrastructure are preserved.

A Node generator (`landing/tools/site/`) defines header/footer/meta/components and bilingual content once; committed static output is what is served (17 pages).

## 8. Security (Implemented)

- HTTPS/HSTS/CSP headers via Express (`src/app.js`): CSP `default-src 'self'; script-src 'self' 'unsafe-inline' 'wasm-unsafe-eval' ...; style-src 'self' 'unsafe-inline'; img-src 'self' data: https:; ...`, plus X-Frame-Options DENY, X-Content-Type-Options nosniff, Referrer-Policy, Permissions-Policy, COOP.
- `_headers` for static host: nosniff, X-Frame-Options DENY, Referrer-Policy, Permissions-Policy, COOP, cache rules, immutable assets.
- Server-side validation (Zod), sanitization, escaping, rate limiting, spam protection (honeypot + timing), CORS.
- Consent mandatory (`CONSENT_REQUIRED`); consent IP stored as `consentIpHash` (SHA-256 prefix), not raw IP; contact IP as `ipHash`.
- Waitlist consent is mandatory; confirmation email is transactional with one-click unsubscribe token.
- Contact messages stored in `landing_contact_messages`; support notified by email; no auto-reply to submitter (no mail-relay abuse).
- Confirmation/best-effort: signup/message succeeds even when no mail channel configured (`confirmationStatus`/`notificationStatus` recorded).
- Re-subscribing after unsubscribe = fresh consent, new token, new confirmation email.
- Admin waitlist broadcast skips `status === 'unsubscribed'` / `unsubscribedAt` entries.
- No public subscriber DB/export; admin endpoints behind admin secret.
- No analytics added (none configured); cookie policy documents only essential localStorage + Cloudflare security cookies → no consent banner needed (documented tradeoff).
