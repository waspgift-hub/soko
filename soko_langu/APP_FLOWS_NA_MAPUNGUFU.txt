================================================================================
SOKO VIBE — FLOW ZA APP NA MAPUNGUFU (GAPS)
Maelezo kamili ya jinsi app inavyofanya kazi + mapungufu yote yanayojulikana
Tarehe: 2026-08-08
================================================================================

Maelezo ya muhtasari:
- App: Flutter (soko_langu/lib)
- Backend: Node/Express (soko_langu/server/index.js, ~7,500 mistari, 118+ endpoints)
- Payment provider: ClickPesa pekee (collection, payout, refund)
- Notifications: OneSignal + Firestore fallback + SMS (Meseji/NotifyAfrica)
- Admin panel: hosting/admin.html (Firebase Hosting) + admin screens ndani ya app
- Search/Notification routers zilizopachikwa: server/search.js, server/notification.js
- Listener ya Firestore: server/listener.js (OneSignal + SMS triggers)

SEHEMU A: FLOW KUU ZA APP
================================================================================

------------------------------------------------------------------------------
A1. App STARTUP (Initialization Flow)
------------------------------------------------------------------------------
1. main() inaanza:
   - WidgetsFlutterBinding.ensureInitialized()
   - Firebase.initializeApp (firebase_options.dart)
   - Firestore persistenceEnabled = true
   - LocalCacheService.init() (Hive)
   - Global error handlers → Crashlytics
   - GoogleSignIn.instance.initialize()
   - LocalNotificationService().initialize() (heads-up channels)
   - runApp(SokoVibeApp)
2. _SokoVibeAppState.initState:
   - Kujenga ProductFeedProvider, AuthRepository, OnboardingService, AuthNotifier
   - _initApp(): theme load, language (default 'en'), currency (default 'TZS'),
     AuthNotifier.initialize(), appStateNotifier.setAppInitialized(),
     MagicLinkService.initialize(), AppLockService.load(), background services
3. _initBackgroundServices: Crashlytics, Performance, AppCheck, AdMob,
   SecurityService, notificationService.initialize() (OneSignal), ExchangeRate,
   AiService.
4. AuthGate (Consumer<AuthNotifier>) huamua skrini ya kwanza:
   - loading → skeleton
   - onboarding → OnboardingScreen
   - unauthenticated → LoginScreen
   - authenticated + suspended → SuspendedPage
   - authenticated + needsProfileSetup → ProfileSetupScreen
   - authenticated → MainScreen (bottom nav)

------------------------------------------------------------------------------
A2. ONBOARDING + KUSAJILI (Register) + KUINGIA (Login)
------------------------------------------------------------------------------
ONBOARDING:
- OnboardingScreen → AccountSelectionScreen → hifadhi account_tier (prefs) →
  RegisterScreen au LoginScreen.

USAJILI (Register):
1. RegisterScreen: form + sheria (acceptedTerms) + password match validation
2. Normalize simu: '0' → '255' prefix
3. POST /api/auth/check-phone → kama exists, error
4. POST /api/auth/check-email → kama exists, error
5. AuthNotifier.sendPhoneOtp() → POST /api/auth/send-otp (MesejiService)
6. OtpScreen._verify: tarakimu 6 → POST /api/auth/verify-otp
7. Ikiwa valid → AuthRepository.register() → createUserWithEmailAndPassword +
   updateDisplayName + _createProfile (Firestore users/{uid})
8. Update users/{uid}.phone + AccountManager.addOrUpdateAccount()
9. popUntil first route

KUINGIA (Login):
- Njia: Email+password (login), Google Sign-In, OTP ya simu (/api/phone-login
  inarudisha custom token), Magic Link (/api/auth/... email link).
- Kila njia inafuata: markCompleted → _setAuthState → _fetchAdminStatus →
  _checkSuspended → _checkProfileCompleteness → _syncAppState.
- Login ya simu: normalize → POST /api/phone-login → signInWithCustomToken →
  _ensureProfileExists. NOTE: password inatokana na tarakimu 6 za simu + suffix
  ('Sv!') — dhaifu lakini app haitaji.

ROUTER GUARDS:
- _authRequiredRoutes: checkout, kyc, addProduct, profile, settings, editProfile,
  shopCustomization, wishlist, myAds, sellerDashboard, sellerEarnings,
  sellerDispatch, sellerQuote, sellerOrders, myPurchases, productBoost,

  orderDetail, report.

  admin@soko-langu.com + isAdmin).

     POST /api/transactions/create

     dispatch {orderId, userId, busName, plateNumber, trackingNumber, note}
